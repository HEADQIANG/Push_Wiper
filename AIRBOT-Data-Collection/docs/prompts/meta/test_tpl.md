# 测试程序要求

- 使用unittest或不使用任何测试框架
- 使用符合hydra规范的yaml文件动态配置（使用_target_进行动态实例化）
- 基于argparser通过命令行参数传递配置文件路径等测试所需参数（--cfg）
- 确保待测对象的对外声明的方法/属性均被纳入测试，且遵循合理的调用顺序
- 测试文件命名均以 test_ 为前缀
- 测试产生的临时过程文件使用 tempfile 进行管理，确保测试结束后清理；产生的结果文件（用于人工检查）放在测试文件同目录下的 outputs 文件夹中（如果涉及的话）
- 如果无法推断测试所需的前置输入（例如示例payloads等），请先提出需求让开发者补充后再继续
- 测试文件运行前终端先进入 airdc 工程目录
