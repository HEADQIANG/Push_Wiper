# 文档模板定义

## Module

模板定义如下：

首先概述模块的作用，指出模块基类所在的文件路径及类名。

### 必要方法/属性

介绍模块基类中必须实现的方法、属性，给出方法签名和完整说明。
注意：模块基类通常继承自`ConfigurableBasis`，需要额外增加`__init__`和`on_configure`方法的说明。

### 可选方法/属性

介绍模块基类中可选覆盖的方法、属性，给出方法签名和完整说明。这些方法通常有默认实现，因此需要对默认的功能进行说明。

### 方法调用时机

说明模块在运行过程中各方法的调用顺序和时机。例如，对于`ConfigurableBasis`的子类，
在实例化时只是将config保存为属性，而后会先调用父类的`configure`方法，其中会调用`on_configure`方法完成最终的配置。
